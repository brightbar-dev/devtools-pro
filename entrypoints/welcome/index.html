Brightbar DevTools is installed

Inspect any page without opening DevTools

Thirteen tools, and every one is free. No account, no paywall.

Start in two steps

  1. Pin it. Open the extensions menu (the puzzle piece) in the browser toolbar and click the pin next to Brightbar DevTools.
  2. Use it. On any page, click the Brightbar DevTools icon and pick a tool. Press Esc to stop.

Brightbar DevTools asked for no access to your sites when you installed it. It only touches the page you click it on, and only after you pick a tool. No tracking, no ads.

The tools

    Keys while a tool is on

    Esc
    Stop inspecting, in every frame
    Click
    Pin the panel (Measure: anchor · Grid: keep overlay · Live Edit: select)
    S
    Screenshot the hovered element
    C / T
    CSS Inspector: copy as CSS / as Tailwind classes
    E / P
    Color Picker: eyedropper / page palette
    I
    Font Detector: every font on the page
    Alt + hover · drag
    Measure: distances to the anchor · a ruler
    ⌘Z / ⇧⌘Z
    Live Edit: undo / redo (Ctrl on Windows and Linux)
